# Fotos de animales por caravana

Colocar aquí fotos de ejemplo usando el número de caravana visual como nombre.
Eliminar los espacios y conservar los ceros iniciales.

Ejemplo: para la caravana `003 1295`, agregar `0031295.jpg`.
También se admiten `.jpeg`, `.png` y `.webp`, con extensión en minúsculas.
Si hay varios formatos del mismo número, se elige JPG, JPEG, PNG y WebP, en ese orden.

Después de agregar una foto, detener y volver a ejecutar la app para incluirla
en el bundle de Flutter. La foto local capturada durante un pesaje tiene prioridad.
Si no hay ninguna foto, se conserva el círculo del encabezado.

Estas fotos forman parte de la app compilada: son ejemplos para probar el
detalle. Las capturas reales siguen guardándose únicamente en el dispositivo.
La búsqueda de ejemplos usa solo la caravana visual; si el mismo número existe
en varios establecimientos, mostrará la misma foto de ejemplo en todos ellos.
